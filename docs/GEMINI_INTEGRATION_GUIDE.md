# Gemini AI Integration Guide

## Overview

The system uses **Gemini-first** approach with graceful fallback and user notifications.

```
User Query
    ↓
🔵 Try Gemini API (primary)
    ↓
✅ Success? → Return with "✓ Generated by Gemini"
    ↓
❌ Failed?
    ↓
🔄 Activate Fallback System:
    1. Semantic Cache (⚡ faster)
    2. Hugging Face (🤖 alternative AI)
    3. Templates (📚 offline)
    ↓
✅ Always get a response
    ↓
🔔 User notified of source
```

## Usage

### Basic Usage

```typescript
import { generateAIContent, formatAIResponse } from '@/services/geminiAIService';
import { AIResponseNotification } from '@/components/ai/AIResponseNotification';

async function handleGenerateContent() {
  // Generate content
  const response = await generateAIContent(
    'Create a lesson plan for teaching fractions to primary 5 students',
    { 
      userRole: 'Teacher',
      subject: 'Mathematics',
      grade: 'Primary 5'
    }
  );

  // Format for display
  const formatted = formatAIResponse(response);

  // Show notification to user
  return (
    <div>
      <AIResponseNotification response={formatted} />
      <div>{formatted.content}</div>
    </div>
  );
}
```

### Full Example Component

```typescript
import React, { useState } from 'react';
import { generateAIContent, formatAIResponse } from '@/services/geminiAIService';
import { AIResponseNotification } from '@/components/ai/AIResponseNotification';

export function LessonPlanGenerator() {
  const [loading, setLoading] = useState(false);
  const [response, setResponse] = useState(null);

  const handleGenerate = async () => {
    setLoading(true);
    try {
      // Call AI service
      const aiResponse = await generateAIContent(
        'Create a lesson plan for teaching fractions',
        { userRole: 'Teacher', subject: 'Mathematics' }
      );

      // Format response with notification
      const formatted = formatAIResponse(aiResponse);
      setResponse(formatted);
      
    } catch (error) {
      console.error('Generation failed:', error);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div>
      <button onClick={handleGenerate} disabled={loading}>
        {loading ? 'Generating...' : 'Generate Lesson Plan'}
      </button>

      {response && (
        <>
          {/* Show source notification */}
          <AIResponseNotification response={response} />
          
          {/* Show content */}
          <div className="prose">
            {response.content}
          </div>
        </>
      )}
    </div>
  );
}
```

## Error Handling

### All Systems Work
```
User → Gemini → ✅ Response
Notification: "✓ Generated by Gemini AI"
```

### Gemini Fails, Fallback Works
```
User → Gemini → ❌ Failed
     → Semantic Cache → ✅ Response
Notification: "⚡ Using cached response"
```

### Gemini + Fallback Fail (Rare)
```
User → Gemini → ❌ Failed
     → Fallback → ❌ Failed
     → Emergency Message
Notification: "⚠️ System temporarily unavailable"
```

## Configuration

### Gemini API Settings

The system uses:
- **Model**: `gemini-pro`
- **Temperature**: 0.7
- **Max Tokens**: 2048
- **Timeout**: 30 seconds
- **Safety**: Block medium and above

### Fallback Chain

1. **Semantic Cache** (instant, 70%+ similarity)
2. **Hugging Face** (if API key configured)
3. **Templates** (always available)

## Best Practices

### 1. Always Use Formatted Response

```typescript
// ✅ Good - users see the source
const response = await generateAIContent(prompt);
const formatted = formatAIResponse(response);
return <AIResponseNotification response={formatted} />;

// ❌ Bad - users don't know the source
const response = await generateAIContent(prompt);
return <div>{response.content}</div>;
```

### 2. Handle Loading States

```typescript
const [loading, setLoading] = useState(false);

const generate = async () => {
  setLoading(true);
  try {
    const response = await generateAIContent(prompt);
    // ...
  } finally {
    setLoading(false);
  }
};
```

### 3. Log Important Events

```typescript
const response = await generateAIContent(prompt);

// Log for analytics
if (response.isFallback) {
  console.log('Fallback used:', response.source, response.fallbackReason);
  // Track in analytics
  analytics.track('ai_fallback_used', {
    source: response.source,
    reason: response.fallbackReason
  });
}
```

## Troubleshooting

### Issue: No Gemini API Key

**Symptom:** Always using fallback

**Solution:**
```typescript
import { getGeminiAIService } from '@/services/geminiAIService';

const service = getGeminiAIService();
console.log('Has key:', service.hasGeminiKey());

if (!service.hasGeminiKey()) {
  service.setGeminiKey('AIzaSy...');
}
```

### Issue: Gemini API Errors

**Common Errors:**
- `API key not configured` - Set API key
- `429 Too Many Requests` - Rate limited, fallback activates
- `401 Unauthorized` - Invalid API key
- `Request timed out` - Network issue, fallback activates

**Check:**
```typescript
const status = service.getStatus();
console.log('Last error:', status.lastGeminiError);
```

### Issue: Fallback Not Working

**Check:**
```typescript
import { generateFallbackResponse } from '@/services/fallbackAiService';

// Test fallback directly
const response = generateFallbackResponse({
  prompt: 'Test',
  context: {}
});

console.log('Fallback works:', !!response);
```
